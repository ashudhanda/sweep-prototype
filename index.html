Unused apps

30+ DAYS INACTIVE

Archive before uninstalling.

Keep app data and its launcher icon while Android removes reclaimable install files. If system archiving isn't available, Sweep opens the normal uninstall flow.

System app archiving is used by Samsung and Nothing OS; Samsung's flow keeps app data and the icon. Availability depends on the device.

Recently deleted

30-DAY RECOVERY

Undo a cleanup mistake.

Reviewed files stay recoverable before permanent removal. Restore a file anytime or delete it permanently after a separate confirmation.

A 30-day trash is documented in Samsung Device Care and WhatsClean. Samsung's storage guide confirms its 30-day recycle bin.

Private vault

ANDROID BUILD

Protected storage needs the real app.

A secure vault depends on Android encryption and device authentication, so it isn't simulated in this tappable preview.

Planned after core cleanup

The first working build will prioritize safe scanning, review, permissions and Recently deleted. Vault setup comes after those flows pass device testing.
